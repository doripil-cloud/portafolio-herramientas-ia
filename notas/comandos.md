\# Comandos que aprendí



\## Terminal



| Comando | Para qué sirve |

|---|---|

| `pwd` | Saber en qué carpeta estoy |

| `ls` | Ver qué hay en la carpeta (`-l` detalles, `-a` ocultos) |

| `cd carpeta` | Entrar a una carpeta (`cd ..` sube, `cd \~` va a mi carpeta personal) |

| `mkdir nombre` | Crear una carpeta |

| `touch archivo` | Crear un archivo vacío |

| `cp origen destino` | Copiar |

| `mv origen destino` | Mover o renombrar |

| `rm archivo` | Borrar (`rm -r` para carpetas) |

| `cat archivo` | Ver el contenido de un archivo |

| `clear` | Limpiar la pantalla |

| `>` | Guardar la salida en un archivo (lo reemplaza) |

| `>>` | Agregar la salida al final de un archivo |

| `\\|` | Pasar la salida al siguiente comando |

| `wc -l` | Contar líneas |

| `head` | Ver las primeras líneas |

| `sort` | Ordenar |

| `chmod +x hola.sh` | Hacer ejecutable un script |

| `sudo comando` | Ejecutar como administrador |



\## Git



| Comando | Para qué sirve |

|---|---|

| `git add` | Preparar cambios para el commit |

| `git commit -m` | Guardar una foto de los cambios con un mensaje |

| `git log --oneline` | Ver un commit por renglón, del más nuevo al más viejo |

| `git log` | Ver commits con autor y fecha |
